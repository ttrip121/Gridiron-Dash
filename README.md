# Gridiron-Dash

A single-file HTML5 canvas college-football runner. Juke the defense with the left/right arrow keys and reach the end zone. Each touchdown raises the level (the defense tracks harder); reach level 10 to win. Getting tackled resets everything.

## Play

Open `index.html` in any modern browser. No build step or dependencies.

## Controls

| Key | Action |
| --- | --- |
| Space | Toggle conference colorway (home screen) |
| Enter | Kick off / next drive |
| Left / Right arrows | Juke defenders |
| Esc | Return to the home screen |
